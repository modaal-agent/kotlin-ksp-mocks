A test against a mock generated by the dev.modaal mocks-processor fails with

```
java.lang.IllegalStateException: loadHandler expected to be set.
```

```kotlin
@Test
fun `the page is loaded`() = runTest {
  val environment = FeedEnvironmentMock()

  val page = environment.load("p1")

  assertEquals("p1", page.id)
  assertEquals(1, environment.loadCallCount)
}
```

```kotlin
interface FeedEnvironment {
  suspend fun load(id: String): FeedPage
}
```

What is it telling me, and when does a mock return something without me setting anything?
