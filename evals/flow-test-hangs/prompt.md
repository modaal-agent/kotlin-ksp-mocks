This test never returns. After a minute it fails with

```
kotlinx.coroutines.test.UncompletedCoroutinesError: After waiting for 1m, the test body did not run to completion
```

```kotlin
@Test
fun `events reach the collector`() = runTest {
  val environment = FeedEnvironmentMock()
  environment.eventsChannel.trySend(FeedEvent.Tick)

  assertEquals(listOf(FeedEvent.Tick), environment.events().toList())
}
```

`FeedEnvironmentMock` is generated by the dev.modaal mocks-processor from

```kotlin
interface FeedEnvironment {
  fun events(): Flow<FeedEvent>
}
```

Why does it hang, and what do I change?
